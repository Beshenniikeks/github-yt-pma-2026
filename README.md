Ve variantě XML je vzhled obrazovky definován v souboru activity_main.xml. Kód v MainActivity.kt získá odkaz na TextView pomocí findViewById a aktualizuje zobrazenou kostku přímým nastavením tvDice.text. Otáčení a změny symbolů během hodu řídí ValueAnimator.Ve variantě Jetpack Compose je rozhraní vytvořeno přímo v Kotlinu pomocí funkcí označených @Composable. Hodnota kostky je uložena ve stavu diceValue pomocí rememberSaveable a mutableIntStateOf. Při změně tohoto stavu Compose aktualizuje příslušnou část rozhraní a zobrazí odpovídající symbol. Animace využívá korutiny, Animatable a graphicsLayer.
Hlavní rozdíl spočívá ve způsobu aktualizace rozhraní: v XML variantě přímo měníme vlastnosti konkrétního prvku, zatímco v Compose měníme stav, ze kterého se výsledné rozhraní odvozuje.
